# Breakthrough Mods Reflection

### What was the hardest part of this project? Why did you have a harder time with this part? (Minimum 2 Sentences)

The hardest part of the project were the screens such as the start screen and the win/lose screen. I didn't really understand how they did it the first time and what made it work so it was muhc harder than just adding a power-up or so.

### What part or parts of this project did you find easy? Why were these parts easier? (Minimum 2 Sentences)

The easiest part was adding new power-ups. The tutorials made it really easy to expand on the code, by using image sprites and random indexing.

### Debugging is an important part of the iterative design process. Describe a bug you encountered and how you went about fixing it. (Minimum 4 Sentences)

A bug I encountered was with making the extra ball. At first, I wanted to just change the variables of the existing obj_ball object, but figured that there was many more things that I wanted to change than just the sprites or speed, such as the behaviors. I navigated around this by making a different object which let me change the behavior of specifically the extra balls. Making a new object entirely also allowed me to fix a bug where it would spawn new bats instead of balls.
